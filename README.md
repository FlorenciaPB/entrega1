
📌 Descripción del Proyecto

Este proyecto consiste en el análisis de interacción e identificación de las interfaces de entrada (inputs) y salida (outputs) de una tostadora de uso cotidiano. El objetivo principal es clasificar y mapear cómo el usuario interactúa con el artefacto y cómo este responde sensorialmente.  



El análisis está integrado en una interfaz web interactiva que permite explorar la lámina gráfica explicativa y revisar sus vistas en detalle.  


🗂️ Clasificación de Interfaces

📥 Entradas (Inputs)
Palanca de encendido/bajada (Física): Mecanismo manual que inicia el ciclo de tostado y engancha el electroimán.  


Perilla de nivel de tostado (Física): Control giratorio continuo/discreto para seleccionar el tiempo/temperatura de tostado.  


Botones de función / Cancelar (Física): Interruptores de presión para detener el proceso o activar modos específicos (descongelar/recalentar).  


📤 Salidas (Outputs)
Calor de las resistencias (Física/Térmica): Transferencia de energía térmica para tostar el pan.  


Expulsión mecánica del pan (Física): Salida mediante resorte al finalizar el ciclo de temporización.  


Indicadores LED (Visual/Gráfica): Luz de confirmación de estado activo o función seleccionada.  


Señal sonora / "Click" (Acústica): Sonido mecánico seco al soltarse el mecanismo y concluir el proceso.  


📸 Vistas y Material Gráfico
La aplicación web permite alternar entre tres vistas principales del análisis:

Entrada (input.jpg): Identificación visual de los controles e interfaces con los que interactúa el usuario.  


Salida (output.jpg): Respuesta del electrodoméstico e indicadores de estado.  


Vista Explotada (vista explotada.jpg): Desglose del artefacto para la comprensión de sus componentes internos.
